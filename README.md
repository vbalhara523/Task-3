# Mall Customers Clustering Analysis

This repository contains the Python script used to perform K-Means clustering on the Mall Customers dataset.

## Objective
To apply unsupervised learning techniques to segment customers based on annual income and spending scores.

## Tools Used
- Python
- Pandas
- Scikit-Learn
- Matplotlib

## Process Highlights
- Data preprocessing using StandardScaler.
- Determination of optimal clusters using the Elbow Method.
- Implementation of K-Means clustering (K=5).
- Visualization of customer segments and cluster centroids.
